Floating voice widget

This page loads the official Vapi HTML widget from a CDN. Look for the talk button (usually bottom-right), click it, allow your microphone, and start a conversation.

Configuration needed. Copy config.example.js to config.js, add your Vapi public key and assistant ID, then refresh this page.

Checklist

  1. Open this file with Live Server (not double-click).
  2. Ensure config.js exists next to this HTML file.
  3. Try: “I’d like to book a test drive for an SUV in Mumbai.”

Trainer note: Microphone access requires http://localhost or HTTPS. Use Live Server or host this folder on any static file server.
